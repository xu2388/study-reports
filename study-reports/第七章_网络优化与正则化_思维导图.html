网络优化 优化算法 参数初始化 数据预处理 逐层规范化 超参数优化 网络正则化 训练诊断
第七章 · 网络优化与正则化优化（找到好解）＋ 泛化（避免过拟合）
本章定位
优化问题非凸函数、参数多、一阶优化收敛慢、梯度消失 / 爆炸
泛化问题模型复杂度高、拟合能力强 → 过拟合
总目标在表示能力、复杂度、学习效率、泛化能力之间找平衡
①网络优化让经验/结构风险最小化 · 非凸 + 高维优化问题
网络结构多样性CNN / RNN / GNN 结构各异 → 无通用优化法；超参数多，挑战大
▶高维非凸优化与低维不同，难点不是局部最优，而是逃离鞍点
鞍点梯度为 0 但非极值；高维中主要难点，随机梯度有助于逃离
平坦 vs 尖锐最小值平坦更鲁棒、泛化更好
局部最小解近似等价找泛化好的解，而非精确追求全局最优
梯度消失 / 爆炸深度网络训练的主要难点
改善方法更好的优化算法 · 更好的初始化/预处理 · 修改结构改善地形（ReLU/残差/规范化）· 超参数优化
②优化算法三大类：调学习率 · 修正梯度估计 · 利用结构/平坦性
▶小批量梯度下降Mini-Batch GD
批大小选择越大方差越小、越稳定，可配大学习率（线性缩放规则）
大批量 → 尖锐最小值小批量 → 平坦最小值（泛化更好）
梯度累积显存受限时，分小批累加梯度再更新，等价于大批量
▶学习率调整学习率过大不收敛、过小收敛慢
学习率衰减分段常数 / 逆时 / 指数 / 自然指数 / 余弦衰减
学习率预热 Warmup初期小学习率再恢复，稳定大 batch 训练
周期性调整循环学习率 · SGDR 带热重启的余弦衰减（助逃离尖锐/鞍点）
自适应学习率AdaGrad / RMSprop / AdaDelta（每个参数单独调学习率）
▶梯度估计修正缓解随机梯度振荡，提高速度
动量法梯度的加权移动平均；方向一致时加速、振荡时减速
Nesterov 加速在「预更新点」处计算梯度，前瞻一步
Adam动量 + RMSprop，一阶/二阶矩 + 偏差修正
Muon矩阵结构优化器：动量方向做正交化，配 AdamW 混用
SAM最坏扰动附近最优化，倾向平坦最小值、兼顾泛化
▶梯度截断应对梯度爆炸
按值截断梯度钳制到 [a, b] 区间
按模截断模超过阈值则整体缩放；RNN 训练常用
③参数初始化初始值影响收敛效率与泛化能力
预训练初始化大规模数据预训练 → 目标任务微调（Fine-Tuning）
▶随机初始化打破「对称权重」现象（全 0 会导致神经元无区分性）
固定方差高斯分布 / 均匀分布采样
Xavier 初始化按层神经元数缩放方差，适配 Sigmoid / Tanh
He 初始化适配 ReLU（方差约为 Xavier 的 2 倍）
正交初始化SVD 取正交矩阵 → 范数保持，防梯度消失/爆炸；RNN 常用
固定值初始化偏置按经验设置：LSTM 遗忘门 = 1~2、ReLU 神经元 = 0.01
④数据预处理特征尺度差异大 → 梯度下降效率差
最小最大值规范化把特征映射到 [0, 1]
标准化 Z-score调整为均值 0、方差 1
白化PCA 去除特征间相关性，同方差
⑤逐层规范化对隐藏层输入规范化 → 训练更稳定高效
作用缓解内部协变量偏移 · 平滑优化地形 · 允许更大学习率
批量规范化 BN按小批量对单个神经元规范化；CNN / 大批量场景
层规范化 LN对整层所有神经元规范化；RNN / Transformer / 小批量
RMS 规范化省去减均值，只按 RMS 缩放；现代大模型常用
权重规范化重参数化：把权重分解为「长度 + 方向」
局部响应规范化 LRNAlexNet 早期方法，现已少用
⑥超参数优化组合优化问题 · 单次评估代价高
网格搜索穷举所有组合，效率低
随机搜索随机组合采样，实践中常优于网格
贝叶斯优化高斯过程建模 + 收益函数（EI 等）· SMBO
动态资源分配逐次减半 Successive Halving · HyperBand
神经架构搜索 NASRL 控制器自动生成网络架构
⑦网络正则化限制模型复杂度 · 提高泛化能力 · 避免过拟合
▶参数约束类传统机器学习常用
ℓ1 正则化促使参数稀疏
ℓ2 正则化抑制参数过大
弹性网络ℓ1 + ℓ2 折中
权重衰减参数更新乘 (1−β)；标准 SGD 下与 ℓ2 等价
AdamW解耦权重衰减（与「Adam + ℓ2」不等价，泛化更好）
提前停止Early Stopping：验证集错误不再下降即停止迭代
▶暂退法 Dropout随机屏蔽部分神经元输出
反向缩放训练时除以 p、测试时不变，期望尺度一致
集成学习解释每次采样不同子网络，≈ 指数级子网络的集成
贝叶斯学习解释对参数分布的近似采样
RNN 用法只屏蔽非循环连接，或变分暂退法（时间维共享掩码）
▶数据增强提高样本多样性、增强鲁棒性
几何变换 / 噪声旋转 · 翻转 · 缩放 · 平移 · 加噪声
mixup两个样本及标签做凸组合
CutMix局部区域替换 + 按面积比例混合标签
▶标签平滑给 one-hot 标签加入噪声 → 软目标
软目标避免模型过于自信、改善概率校准
知识蒸馏教师网络的软标签 → 训练学生网络
⑧训练过程诊断观察损失 / 梯度 / 参数范数 / 置信度，定位问题
训练+验证损失都高→ 容量不足：增大模型/步数，调初始化与预处理
训练低、验证高→ 过拟合/数据泄漏：加强正则化，检查数据划分
损失振荡 / NaN→ 学习率过大/梯度爆炸：预热、梯度截断、混合精度
准确率高但置信度不可靠→ 校准问题：标签平滑、温度缩放
数据使用边界训练集调参 / 验证集选模型 / 测试集仅做最终评估
默认训练配方：合适的参数初始化 + 数据预处理 → AdamW + 学习率预热 + 余弦衰减 → 按需加入规范化、权重衰减、数据增强、标签平滑。
