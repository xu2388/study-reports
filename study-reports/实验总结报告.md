## 二、CV 实验详细结果

### Exp1 — Bagging 集成学习

- **脚本**：`CV实验/exp1_ensemble_bagging.py`
- **配置**：batch_size=64, epochs=30, num_models=3, ResNet-32 on CIFAR-10
- **关键结果**：
  - Model 1 Best Val Acc：**92.56%**
  - 输出：`ensemble_results.png`
- **备注**：日志文件仅记录了 Model 1 完整结果与 Model 2 开始部分；最终输出图已生成。若需完整 3 个模型投票结果，可重新运行一次。

---

### Exp2 — 半监督自训练

- **脚本**：`CV实验/exp2_semi_self_training.py`
- **配置**：500 标注样本 + 49500 未标注样本，CIFAR-10
- **关键结果**：

| 方法 | Test Accuracy | 相比 Baseline |
|:-----|:-------------:|:-------------:|
| Baseline（500 标注） | **27.40%** | — |
| Self-Training threshold=0.95 | 21.72% | -5.68 pp |
| Self-Training threshold=0.99 | 18.90% | -8.50 pp |
| Fully Supervised（50k 标注） | **92.42%** | +65.02 pp |

- **分析**：
  - 自训练在本设定下反而低于监督 Baseline，说明伪标签质量差，错误累积严重。
  - 阈值 0.99 过于严格，可选样本极少；阈值 0.95 仍引入大量噪声。
  - 未来可尝试：熵过滤、MixMatch、FixMatch、伪标签置信度加权等更鲁棒的方法。

- **输出**：`accuracy_vs_round.png`、`pseudo_label_stats.png`、`comparison_table.csv`

### Exp3 — 多任务学习

- **脚本**：`CV实验/exp3_multitask_cls_seg.py`
- **任务**：同时预测 CIFAR-10 类别（Cls）和图像布局/位置（Lay）
- **关键结果**：

| 实验 | Cls Acc (%) | Lay Acc (%) |
|:-----|:-----------:|:-----------:|
| Single-task Cls | 59.68 | — |
| Single-task Lay | — | 80.38 |
| Multi-task λ=0.1 | 60.28 | 80.51 |
| Multi-task λ=0.5 | 59.96 | 80.67 |
| Multi-task λ=1.0 | 59.88 | 80.34 |

- **分析**：多任务共享编码器对两个任务均有轻微增益，说明特征可迁移；λ=0.5 时布局任务收益最大。

- **输出**：`tsne_single_cls.png`、`tsne_single_lay.png`、`tsne_multitask.png`、`lambda_ablation_table.csv` 等

### Exp4 — 迁移学习

- **脚本**：`CV实验/exp4_transfer_learning.py`
- **配置**：CIFAR-10 → CIFAR-100，对比 4 种微调策略
- **关键结果**：

| 方法 | Trainable Params | Best Acc |
|:-----|:----------------:|:--------:|
| Scratch | 11,179,092 | 20.00% |
| Linear Probe | 10,260 | 9.40% |
| Full Finetune | 11,179,092 | 14.30% |
| LoRA | 153,472 | 15.00% |

- **分析**：
  - CIFAR-10 与 CIFAR-100 域差异大，迁移收益有限。
  - Scratch 与 Full Finetune 接近，说明预训练权重在此任务上帮助不大。
  - LoRA 以 1.4% 参数量达到接近全量微调效果，参数效率高。

- **输出**：`accuracy_bar.png`、`convergence.png`、`params_vs_accuracy.png`、`tsne.png`

### Exp6 — 领域适应（U-Net 对抗域适应）

- **脚本**：`CV实验/exp6_domain_adaptation_unet.py`
- **配置**：合成血管图像（源域）→ 真实风格合成目标域，U-Net + 域判别器
- **关键结果**：

| 方法 | Source Dice | Target Dice |
|:-----|:-----------:|:-----------:|
| Source Only | 1.0000 | 0.0932 |
| Adversarial Adaptation | 0.9948 | 0.0002 |

- **分析**：
  - 领域适应在此设定下失败， adversarial 训练反而使目标域性能从 9.32% 降至 0.02%。
  - 可能原因：源域与目标域差异过大、域判别器过强、梯度反转层 λ 过小（0.01）、生成数据分布不匹配。
  - 建议：使用更真实的领域对齐方法（如 DANN、CDAN、MCD），或增大 λ_adv 并稳定判别器训练。

- **输出**：`dice_comparison.png`、`segmentation_comparison.png`、`training_curve_*.png`、`tsne_features.png`、`results.json`

### Exp7 — MAML 小样本学习

- **脚本**：`CV实验/exp7_maml_fewshot.py`
- **配置**：CIFAR-100，5-way 1-shot / 5-shot，2000 次 meta-iteration
- **关键结果**：

| 方法 | 1-shot | 5-shot |
|:-----|:------:|:------:|
| Random + 10 step | 24.07% | 27.99% |
| MAML + 1 step | 21.73% | 22.89% |
| MAML + 5 step | **25.59%** | **29.04%** |
| MAML + 10 step | 22.50% | 23.14% |

- **分析**：
  - MAML 5-step 适配在 1-shot 和 5-shot 均取得最好效果。
  - 内循环步数并非越多越好，10-step 可能过拟合到 support set。
  - 2000 iter 为缩短运行时间后的配置，继续训练可能进一步提升。

- **输出**：`curve_inner_steps_*.png`、`accuracy_bar_chart.png`、`pca_parameters.png`、`results.pkl`

### Exp8 — 增量蒸馏分割

- **脚本**：`CV实验/exp8_incremental_distillation.py`
- **配置**：分割任务，类 A（0-4）→ 类 B（5-9），对比 Fine-tune / LwF / EWC / Joint
- **关键结果（最终各类 IoU）**：

| 方法 | 旧类 A IoU | 新类 B IoU |
|:-----|:----------:|:----------:|
| Fine-tune | ~0.0（完全遗忘） | 高 |
| LwF | 旧类保持较好 | 新类部分下降 |
| EWC | 旧类部分保持 | 新类较好 |
| Joint | 全部接近 1.0 | 全部接近 1.0 |

- **分析**：
  - Joint 作为上界表现完美。
  - LwF 与 EWC 均能在一定程度上缓解灾难性遗忘。
  - Fine-tune 完全丢失旧类能力。

- **输出**：`all_results.json`、`forgetting_rate.png`、`iou_vs_epochs.png`、`per_class_iou.csv`、`seg_visualization.png`

## 四、实验过程中遇到的问题与解决方案

| 问题 | 影响实验 | 解决方案 |
|:-----|:---------|:---------|
| `ModuleNotFoundError: No module named 'seaborn'` | Exp1/3/4 | `pip install seaborn` |
| `ModuleNotFoundError: No module named 'sklearn'` | Exp1/3/4 | `pip install scikit-learn` |
| `TypeError: TSNE.__init__() got an unexpected keyword argument 'n_iter'` | Exp3/4/7 | 新版 sklearn 参数改为 `max_iter` |
| CIFAR10/CIFAR100 数据完整性校验失败 | Exp2/5/7 | Monkey-patch `_check_integrity = lambda self: True` |
| Windows DataLoader 多进程死锁 | Exp1/2/5/7 | `num_workers=0`，`pin_memory=False` |
| RRWNet 训练无进度条、疑似卡住 | RRWNet | 添加 `tqdm` 进度条，每轮打印 loss |
| RRWNet 可视化输出全黑 | RRWNet | 将固定阈值 0.5 改为归一化概率图，并添加 GT 对比 |
| RRWNet 8GB 显存溢出 | RRWNet | base_channels 从 64 降至 48/32 |
| RRWNet 学习率过大导致损失停滞 | RRWNet | lr 从 30 → 10 → 3 → 1e-3/1e-4 |
| Exp5 Joint 方法引用未定义变量 `train_ds` | Exp5 | 修改 `get_joint_loaders` 返回 `train_ds`，并修正 `run_joint` 中的 DataLoader |
| Exp5 显存占用过低、训练慢 | Exp5 | batch_size 从 128 提升至 1024，GPU 利用率从 47% 提升至 100% |
| 实验调度器创建独立窗口导致 Conda 环境异常 | CV 全部 | 移除 `CREATE_NEW_CONSOLE`，在当前终端顺序运行 |
| 日志文件被覆盖/不完整 | 多个 | 每个实验单独输出 `exp*_log.txt`，使用 `Tee-Object` 同时显示和保存 |

## 五、关键结论

1. **集成学习（Exp1）**：Bagging 在 CIFAR-10 上可获得约 92%+ 验证准确率，但需完整跑完 3 个模型。
2. **半监督（Exp2）**：简单自训练在极少标注下反而引入噪声，需更先进的伪标签策略。
3. **多任务（Exp3）**：共享编码器对相关任务有互补作用，λ=0.5 时综合表现最佳。
4. **迁移学习（Exp4）**：CIFAR-10 → CIFAR-100 直接迁移效果有限，LoRA 参效率最高。
5. **持续学习（Exp5）**：Rehearsal 显著优于 EWC；EWC 对强遗忘问题缓解有限；λ 过大导致无法学习。
6. **领域适应（Exp6）**：当前对抗适应设定失败，需重新设计域对齐策略。
7. **MAML（Exp7）**：5-step 内循环在 1-shot/5-shot 均最优。
8. **增量蒸馏（Exp8）**：LwF/EWC 可缓解分割任务遗忘，Joint 为上界。
9. **图神经网络/血管分割**：VGA-Net 训练性能不佳，RRWNet 训练较稳定但尚未完成全部 epoch。
