## 一、理论学习：教材第9章 图神经网络

### 1.1 图数据基础
- **图的定义**：由节点（Nodes）与边（Edges）构成的非欧氏数据结构
- **图的类型**：无向图/有向图、同质图/异质图
- **图的表示**：邻接矩阵、邻接表、边列表
- **数学性质**：度、同质性/异配性、拉普拉斯矩阵（定义 `L = D - A`）、归一化拉普拉斯矩阵

### 1.2 图上的机器学习任务
- 节点分类（Node Classification）
- 链接预测（Link Prediction）
- 图分类（Graph Classification）

### 1.3 消息传递框架
GNN 的一般框架由消息传递（Message Passing）机制统一描述：
```
h_v^(k) = COMBINE^(k) ( h_v^(k-1), AGGREGATE^(k) ( { h_u^(k-1) : u ∈ N(v) } ) )
```

### 1.4 经典模型学习

| 模型 | 核心思想 | 是否编写代码 |
|------|---------|------------|
| **GCN** | 谱域图卷积的一阶近似，邻域特征加权求和 | ✅ 自行编写 PyTorch 实现 |
| **GraphSAGE** | 归纳式学习框架，支持为新节点生成嵌入 | 下载开源代码学习 |
| **GAT** | 引入自注意力机制，为不同邻居分配不同权重 | ✅ 自行编写 PyTorch 实现 |
| **GIN** | 图同构网络，理论上表达能力最强 | 理论学习 |
| **ChebNet** | 切比雪夫多项式近似谱卷积核 | 下载开源代码学习 |

### 1.5 共性问题
- **过度平滑（Over-smoothing）**：层数过多时所有节点表示趋于一致
- **过压缩（Over-compression）**：信息瓶颈导致远距离信息丢失
- **可扩展性**：大图上的邻居采样与 mini-batch 训练

## 二、自行代码实现

### 2.1 GCN - PyTorch 实现 (`gcn_pytorch.py`)

完整实现了 GCN 模型，在 **Cora 引文网络数据集** 上进行半监督节点分类。

**模型结构**：
```
GraphConvolution(1433, 16) → ReLU → Dropout → GraphConvolution(16, 7) → LogSoftmax
```

**关键技术细节**：
- 对称归一化邻接矩阵：`D^{-1/2} A D^{-1/2}`
- 稀疏矩阵运算（`torch.sparse.mm`）
- Xavier 参数初始化
- 早停机制（patience=10）
- Adam 优化器（lr=0.01, weight_decay=5e-4）

### 2.2 GAT - PyTorch 实现 (`gat_pytorch.py`)

完整实现了 GAT 模型（含多头注意力），在 Cora 数据集上训练。

**模型结构**：
```
Layer 1: 8 头注意力 (1433 → 8×8=64) + 拼接 + ELU
Layer 2: 1 头注意力 (64 → 7) + 平均 + LogSoftmax
```

**关键技术细节**：
- 自注意力系数计算：`e_ij = a^T [W h_i || W h_j]`
- LeakyReLU 激活 + Masked Softmax（仅邻居节点）
- 多头注意力拼接与平均
- 早停机制（patience=100）
- Adam 优化器（lr=0.005, weight_decay=5e-4）
